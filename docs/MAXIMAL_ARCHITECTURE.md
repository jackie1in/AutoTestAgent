```
┌─────────────────────────────────────────────────────────────────┐
│                    MaximalOrchestrator                           │
│                    (最大化测绘编排器)                              │
└─────────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 菜单探索      │    │ Zone发现     │    │ 并行探索      │
│ (递归)        │    │ (结构识别)   │    │ (多实例)     │
└──────────────┘    └──────────────┘    └──────────────┘
        │                     │                     │
        └─────────────────────┼─────────────────────┘
                              ▼

└──────────────┘    └──────────────┘    └──────────────┘
```

## 核心组件

### 1. MaximalOrchestrator
- 整体协调
- 任务分发
- 结果汇总

### 2. MaximalZoneExplorer
- 无步数限制
- 智能策略选择
- 完成度驱动

### 3. RecursiveMenuExplorer
- 递归菜单扫描
- 路径记录
- 状态恢复

### 4. FormCombinationTester
- 字段组合生成
- 边界值测试
- 验证规则测试

## 关键技术

### 完成度计算
```python
completion = (
    0.4 * clicked_ratio +
    0.2 * filled_ratio +
    0.1 * selected_ratio +
    0.2 * submitted_ratio +
    0.1 * modals_tested_ratio
)
```

### 智能策略矩阵
| 页面特征 | 策略 | 任务序列 |
|---------|------|---------|
| 表单 >5字段 | FORM | 扫描→填充必填→填充可选→测试验证→提交→测试重置 |
| 表格 >10行 | TABLE | 扫描→分页→排序→筛选→行操作→批量操作 |
| 菜单 >5项 | MENU | 扫描→展开全部→点击叶子→测试返回 |
| 模态框 >3 | MODAL | 扫描触发器→打开每个→测试操作→测试关闭 |

### 断点续传粒度
- Session 级别：每10分钟
- Zone 级别：每60秒
- 元素级别：每次交互后

## 性能优化

### 并行策略
- 浏览器实例池
- 独立 Cookie/Session
- 资源隔离

### 提前终止
- 完成度达标
- 连续无变化
- 时间预算耗尽
